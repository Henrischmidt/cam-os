## 4. REPRIORITISATION SUGGESTIONS

**Keep the current order for Phases 3–5.** The behavioural layer (Phase 3) is the identity and emotional core — without it the app is a habit tracker, not The 66. iCloud sync (Phase 4) enables the Scriptable widgets (Phase 5); those two are correctly coupled.

**Consider splitting Phase 6 (Polish).**
Animations and haptics can follow live-in; they don't need to precede it. If Cam wants to start Arc 1 as soon as possible, Phase 6 can move to post-launch and Phase 7 (CAM OS integration) promoted. The only hard dependency is that Phase 7 needs a working app to hook into.

**Phase 1 mockup HTML files are a soft blocker for the Phase 6 visual alignment pass.**
No urgency now, but they should land before Phase 6 starts or that phase will again work from written spec only. Low-friction: drop the files into `/mockups/` any time.

**Open review decisions from PR #1 should be resolved before Phase 3 starts**, particularly the identity copy choice — Phase 3 writes more identity-adjacent copy and consistency matters.
